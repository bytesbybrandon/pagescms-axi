# Pages CMS AXI

Use the `pagescms-axi` CLI to read `.pages.yml`, list content, and create or update configured entries.

The CLI uses GitHub CLI authentication and commits content changes to the selected repository.

Pass `--repo OWNER/REPO` or set `PAGESCMS_REPOSITORY` before reading or changing content.

Run `pagescms-axi --help` to see available commands.
